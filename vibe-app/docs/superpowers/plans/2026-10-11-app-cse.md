# APP-CSE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the school's Annual Procurement Plan for Common Supplies and Equipment (APP-CSE): the Procurement Service catalog loaded as reference data, monthly quantities entered in the app, and the official form printed exactly like the owner's `APP.xlsx`.

**Architecture:** a shared read-only catalog (`cse_catalog_items`) loaded from the owner's workbook; one tenant plan per school and fiscal year (`app_cse_plans`) with item rows holding 12 monthly quantities and a price snapshot (`app_cse_items`); one service (`AppCseService`) owns every rule and every calculation; the print only reads the service's totals. The panel lives inside the existing APP tab of Planning.

**Tech Stack:** Laravel 13, PHP 8.4, Blade, PHPUnit feature tests (`RefreshDatabase`), Pint, the project's raw-zip xlsx reading (`ZipArchive` + `SimpleXMLElement`, as `SipWorkbookReader`).

**Spec:** `docs/superpowers/specs/2026-10-11-app-cse-design.md`. Source form: `C:\Users\Bonifacio Orong\Downloads\APP.xlsx`.

## Global Constraints

- Follow the owner's form wording exactly (spec "Official print"). No logos in the header (owner's decision). Do not edit `docs/specs.md` (protected).
- Totals as their labels say: A = sum of every item's total amount; B = A x 0.10; C = A x 0.05; D = A + B + C; G.1/G.2 = per-quarter amounts of Part I/Part II; F = G.1 + G.2.
- Quantities: numbers 0 or more, at most 2 decimals, at most 9,999,999.99. Prices: 0 or more, at most 2 decimals, at most 99,999,999.99.
- Permissions: `planning.manage` changes; `planning.view` or `planning.manage` views and prints. Same school/organization scoping as the SOB (`BelongsToOrganization`, the user's schools only). Closed fiscal year refuses changes (`FiscalYearService::assertOpen`).
- An approved plan is locked: items, header, signatories and removal are refused.
- Signers: the three staff slots use `SignatorySlots` (active staff of the plan's school only).
- Additive, nullable-where-optional migrations; follow project rules: `php artisan make:*`, `vendor/bin/pint --dirty --format agent` before each commit, narrow tests per task and the full suite before the last commit. Commit messages end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Blade pitfall: never put an `@php(...)` line before a later `@endphp` in the same file; use `@php ... @endphp` blocks or plain PHP expressions.

## Review Focus

- A catalog item with no price added without a price is refused (Task 2); the same catalog item added twice, and a second plan for the same school and year, are refused (Tasks 2, 3).
- An approved plan refuses every mutation (items, header, signatories, remove, a second approve) (Task 2).
- Month boxes with negative numbers, more than 2 decimals, text or absurdly large values never cause a 500 and are never saved (Task 3).
- A Part II category or description with HTML or quotes is escaped on the plan page and the print (Task 4).
- A plan keeps printing from its own catalog year and its own price snapshots after a newer catalog year is loaded (Task 4).

**Files:**

**Interfaces:**
- Produces:
  - Table `cse_catalog_items`: `id`, `catalog_year` (unsigned smallint), `category` (string), `code` (string 60), `description` (text), `unit` (string 50), `price` (decimal 14,2 nullable), `sort_order` (unsigned int), timestamps; unique (`catalog_year`, `sort_order`). Model `CseCatalogItem` (not tenant-scoped) with `$fillable` of those columns and `price` cast `decimal:2`.
  - `CseCatalogReader::read(string $xlsxPath): array<int, array{category: string, code: string, description: string, unit: string, price: ?float, sort_order: int}>`: reads the first visible sheet; Part I is the rows after the cell starting "PART I" up to the cell starting "PART II"; a row whose only filled cell is column A with non-numeric text is a category heading; an item row has a code in column B and a description in column C; unit is column D; price is column Z, `null` when blank or 0 or not numeric; descriptions and units are whitespace-normalized; `sort_order` counts item rows from 1. Throws `RuntimeException` with a clear message when there is no "PART I" row or no items.
  - `CseCatalogLoader::load(array $items, int $year): int` inserts the items for `$year` in one transaction and returns the count; throws `RuntimeException` ("The {year} catalog is already loaded.") when the year already has rows.
  - Command `cse:import-catalog {file} {--year=} {--to-json=}`: `.xlsx` is read with the reader, `.json` is decoded; with `--to-json` it writes the JSON and stops; otherwise `--year` is required and the loader runs.
  - `database/data/cse-catalog-2026.json`: the 368 items of the owner's workbook, produced once with `php artisan cse:import-catalog "C:\Users\Bonifacio Orong\Downloads\APP.xlsx" --to-json=database/data/cse-catalog-2026.json`. The load migration reads that JSON and calls the loader for 2026, skipping when 2026 is already loaded.

    - `totals(AppCsePlan $plan): array{a: float, b: float, c: float, d: float, e: ?float, g1: array{q1: float, q2: float, q3: float, q4: float, year: float}, g2: array{...}, f: array{...}}` per the Global Constraints; amounts rounded to 2.
